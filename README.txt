ゲーム名:CIRCLE WARS

概要:好きな武器を使って爽快に敵を倒していき､レベルアップと武器レベルアップで強くなる!!
何回か表れるボスを倒して､Lv100のボスを倒すまで生き残ろう!!豊富な種類の敵や武器､スキルがあり､
戦術性ややり込む要素はたくさん!!自分の好きな武器でラスボスを倒そう!
初心者はHOLY GREAT SWORD(黄色),立ち回りに工夫がいるが無双感がある玄人向け:HANDGUN,MAGIC STAFF(ずっと攻撃をしていてもなかなかうまく行かず､立ち回りに工夫が必要)
真にゲームを楽しむ上級者は初期武器のRUSTY DUGGERかKATANAがおすすめ

動作環境
OS: Linux(RockyLinux)+Windows11
コンパイラ: gcc (C99対応)
ライブラリ: raylib 4.x

※ raylib が事前にインストールされている必要があります。
※ macOS での動作は未検証です。

想定プレイ時間
1プレイあたり約15〜30分（Lv100到達まで）

1.コンパイル方法

1.0 カレントディレクトリが circle_wars であることを確認する
1.1 cd ./build  
1.2 buildファイル内で cmake ..
1.3 make
1.4 ./buildファイル内にcircle_wars　があることを確認
1.5 ./circle_wars でゲーム開始

#トラブルシュート
・起動時に音が出ない：音声ファイルが resources/audio/ に存在するか確認
・ビルドできない：raylib がインストールされているか、cmake .. が成功しているか確認


2.ゲームのやり方

2.1 ゲーム実行を実行
buildファイル内で./circle_warsでコマンドラインから実行しゲーム画面を立ち上げる

2.2 スタート画面が開くと
STARTをクリックまたはENTERキーでゲーム開始
HELPをクリックするとゲームの簡易説明が表示 
QUITをクリックまたはESCキーでゲーム修了

→STARTまたはHELPをクリックし､ゲームを開始しよう!

2.3 基本操作は以下のようにする
移動方法:wasd　(w:前進､s:後退､a:左移動､d:右移動)　　
基本攻撃:spaceボタンを押すごとに所持武器による攻撃をすることができる(遠距離武器は長押しで連続攻撃可能､近距離攻撃では0.1秒長押しでチャージ攻撃可能)

操作一覧
W / A / S / D : 移動
SPACE         : 攻撃（長押しで連続/チャージ）
TAB           : 武器交換
1 / 2 / 3     : スキル選択
P             : 一時停止
CTRL + W      : 必殺技（ゲージMAX時）
ENTER         : ゲーム開始 / リスポーン
ESC           : 終了


2.4 以下のように遊んでみよう!!
-敵を倒してレベルを上げる(移動しながらSPACE連打で敵を倒す!!)
-同じ武器の宝箱を拾う or スキルカード:weapon UP で武器レベルを上げる→強くなる!!　(宝箱の近くでtabキーを押すと武器を交換できる)
-素人向け､玄人向けの色んな武器がある→好きな武器を選ぼう!!
Ex)初心者→HOLY GREAT SWORD
玄人    →HANDGUN,MAGIC STAFF
達人　　→KATANA,RUSTY DAGGER
注意:別の武器を拾うと武器レベルは初期化される→終盤での急激な武器レベル低下はあまり推奨しない(上級者向け)

2.5 最終目的
自分のレベルを上げていってLv.100になったときに出現するボスを倒す
→クリアしたらESCキーやウィンドウを閉じてゲームを終了しよう!


2.6 他のゲーム基本仕様は以下である



-通常の敵はプレイヤーの周りにランダムにスポーンし､レベルに合わせて量や強さが変わる
-レベル5ごとにスキルがランダムに3つ提示され､キーボード(1,2,3)を押して取得する
-レベル20ごとにボスが出現する､ボスは通常の敵より強く弾幕や突進､爆発攻撃を行う
-右下にはwasdの入力を表す十字キーと一時停止PAUSE:P､スペシャル技 ctrl+wを表記している
-右上には今まで生存できた最高レベルのTOP3をランキング形式で表示
-左上には現在のレベル､HP､現在の武器､武器レベル､次のレベルまでの経験値が表示される

#仕様・注意点
・マップは有限サイズであり、外周付近には敵や回復が出にくい仕様
・ゲームバランスの都合上、マップ中央付近での戦闘を推奨
・武器を持ち替えると weaponLevel は初期化される（仕様）
・弾幕の視認性確保のため、弾には寿命が設定されている

2.7 以下は詳細な仕様一覧(武器､敵､スキル)

#武器

共通：武器レベル
武器はマップにランダムに宝箱で配置されている｡種類ごとに色が違う
同じ武器をTABで拾うと weaponLevel++　
近接は斬撃本数が増えるように見える
遠距離は弾数が増える／継続は密度が増える

1) Rusty Dagger（近接）
タイプ: ATK_MELEE
威力/射程: damage=60 / range=200
特徴:SPACE押し→離すで斬撃判定（範囲攻撃）,ためが1秒超かつ射程が短めだと 多段強化, 斬撃中は 敵弾を消せる
見た目/演出: 回転する斬撃線＋先端に白い粒

2) Katana（近接）
タイプ: ATK_MELEE
威力/射程: damage=100 / range=280
特徴: ダガーより射程と威力が伸びた近接版(チャージ可)
見た目: 同じ近接演出だが色がSKYBLUE寄り

3) Holy Great Sword（近接・重）
タイプ: ATK_MELEE
威力/射程: damage=200 / range=420
特徴:射程が長い, 敵弾消し＋広範囲の敵削り
見た目: GOLDの斬撃で派手

4) HANDGUN（遠距離・弾幕）
タイプ: ATK_RANGED
威力/射程: damage=450 / range=800 
発射仕様:SPACE押しっぱで連射, 1回の射撃で 全方位に複数弾, 弾速はプレイヤー弾が速い
見た目: LIMEの弾（丸）

5) MAGIC STAFF（継続系）
タイプ: ATK_CONTINUOUS
威力/射程: damage=65 / range=600 
発射仕様:レベルが弾数に直結, 角度が回転し続け、エリアを流すような圧を放つ
見た目: PURPLE系の弾幕（丸）


#敵
Spider（M_NORMAL）
行動：ひたすらプレイヤーを追尾
特徴：最弱・数で来る基本雑魚
見た目：青い丸
周囲に 8本の脚（時間でうねうね動く）

Golem / Tank（M_TANK）
行動：ゆっくり追尾, 一定時間ごとに 指定地点へ着地 → 爆発
特徴：硬い・範囲攻撃持ち
見た目：四角い岩の体,両腕つき,赤い目

Ghost（M_GHOST）
行動：ふわふわ追尾,一定時間ごとに プレイヤー背後へワープ
特徴：位置ずらし・奇襲が危険
見た目：半透明の丸,下に尾っぽ状の円が連なる幽霊

Charger（M_CHARGER）
行動：いったん距離を取る,その後 高速突進
特徴：直線ダメージ・避けミスると痛い
見た目：三角形,プレイヤー方向を向く,チャージ中は円エフェクト

Shooter（M_SHOOTER）
行動：一定距離を保つ,3方向ショットを周期的に撃つ
特徴：弾幕担当
見た目：楕円形の体,中央に黒い目玉

Worm（M_WORM）
行動：頭が追尾,体が遅れて追従（くねくね）
特徴：当たり判定が長い
見た目：5つの円が連なったミミズ,後ろほど小さい

Ring（M_RING）
行動：プレイヤーの周囲を 円軌道で回る,周期的に狙撃弾
特徴：動きが読みにくい
見た目：二重リング（外円＋内円）

Minion（M_MINION）
行動：高速で追尾
特徴：ボスが召喚する雑魚
見た目：小さめの丸

BOSS（M_BOSS）
行動：
フェーズ1：追尾しながら 放射状弾幕
フェーズ2：柱攻撃（警告円 → 爆発）,ミニオン召喚
特徴：弾幕＋範囲＋雑魚敵召喚の総合ボス
見た目：巨大な多角形（レベルで角数増加）,中央に黒→色付きのコア, 色：RED / PURPLE / GOLD（高Lv）

#スキル
レベルが 5の倍数になるたびに、3択から1つ選び、対応する効果が強化されます。

ATK UP（SKILL_ATK）
取るたび近接・遠距離どちらもダメージUP

SPD UP（SKILL_SPD）
取るたび移動速度UP

REGEN（SKILL_REGEN）
自動回復が定期発動
Lv3以上の進化: 回復が入るたび 最大HPがじわじわ伸びる

RANGE（SKILL_RANGE）
取るたび近接の攻撃範囲,弾の寿命UP

SPECIAL（SKILL_SPECIAL）
必殺ゲージの増加 
必殺（CTRL+W、ゲージ100%）: 全敵にを一層

MAXHP（SKILL_MAXHP）
取るたび,その場で最大HPと現在HPが増える

GACHA（SKILL_GACHA）
取るとランダム武器を提示（Y/Nで装備）
同じ武器ならweaponLevel++、違うなら武器変更＆初期化する

LTNG（SKILL_LIGHTNING）
一定周期で 敵を伝って攻撃するスキル,青い稲妻ライン＋パーティクル

FRZ（SKILL_FROST）
プレイヤー周囲 280以内の敵をスロー
Lv3以上: 完全停止

WPN UP（SKILL_WEAPON_UP）
取るたび weaponLevel++
武器を拾わなくても火力（弾数/斬撃本数）が伸びる


3.工夫した所･評価してほしいアピールポイント

本作品では敵ごとの見た目や挙動､役割を一致させる分かりやすさ､敵を一掃できる爽快感､
プレイヤーの意志によって武器やスキル､行動を変えることができる戦術性を意識した2Dアクションゲームとして設計しました｡以下に詳述する｡

まず､本作品に似たゲームは世に幾つかあるが､それらのゲームと異なる魅力としてあるのが､パックマンのようなシンプルな図形を組み合わせた見た目がむしろ味となって醸すレトロゲーム感と近未来感のあるスピード感やBGMが
成す調和の取れたミックスカルチャーである｡敵の種類にも特徴的で差別化のされた能力や見た目を作ることで､退屈な少ない種類の敵を倒すゲームにありがちな飽きを抑えている｡敵の見た目は行動とリンクするように設計している｡
例えば､接敵してくる敵､突進してくる敵､射撃する敵などに敵の系統を分け､視覚的にも形状を変え､ステレオタイプとして私たちが持つ蜂の突進する敵は三角､射撃する敵は収縮して中の気体を吐き出しそうな丸､重く硬そうな四角形など
を採用することで､ユーザが直感的に次に何が起きるかを瞬時に理解できるようにした｡これにより､敵が増えても理不尽ではなく､理解して対策を考えるというゲーム体験を作ることができた｡

また､Lv5ごとにあるスキルの選択､いわゆるガチャとLv20ごとのボスを加えてことには以下の理由がある｡まず､スキルのガチャはゲームを何周かしても同じ展開にならないようにする装置としての機能がある｡下で述べる
武器のバリエーションにもその機能はあるが､ガチャというランダム要素はおみくじのような自分の運勢を楽しむというお楽しみ要素になる｡加えて､世の中にはガチャを採用したゲームが多くあること､ガチャポンなどが
町中にあることなどもこのシステム導入のハードルを下げているということも考慮した｡

また､武器に多くの種類を用意したのは以下の理由がある｡まず､武器ごとには圧倒的に使いやすい差に差がついている｡HOLY GREAT SWORDは当たり判定が広く､攻撃しやすいのに対し､
KATANAや初期武器のDUSTY DAGGERは真に上級者向けといえる｡なぜなら､BOSSは圧倒的な攻撃力があるのに､これらの近接武器はリーチが短いからである｡また､MAGIC STAFFは広範囲攻撃が
容易にできるため､初心者はこれを連打するだけでゲームの根幹にある爽快感を楽しむことができる｡そして､真に玄人向けがHANDGUNである､ばたつきのある散弾でかつ威力が低いため､縛りプレイのような
ギミックとして､ゲームにやり込み要素を作ることができたと考えている｡このような見た目だけでなく立ち回りの多様化を武器の差別化は作り出すことができた点を評価してほしい｡

また､UIの工夫として､ヘルプ画面を常時呼び出すことができたり､ゲームをPキーで一時停止できるようにしたこと､
レベルや武器､ランキング､WASD操作の視覚化など古き良きドットのあるレトロゲームに近く､所見のユーザに
わかりやすいUIを作ることができた｡

コードの工夫として､
本作品ではモブ､ドロップ､回復､環境ブロックなど多数の要素を同時に扱うため､固定長配列+flagで管理し､動的確保を避けて
安定動作を優先した｡これにより､多数のオブジェクトがあるゲーム後半でも処理が破綻せず､管理が明確になるようにした｡

また､弾幕の処理に寿命をつけたことも挙げたい｡弾幕が多すぎて､ゲーム画面の視認性が悪くなることを考慮し､弾に寿命を持たせて
自然消滅を実装し､射撃頻度の調整を段階的に行った｡特にプレイヤのMAGIC STAFFやHANDGUN等の遠隔武器のfire rateおよび寿命には複数回
の試行を経て最適な値を与えた｡加えて､遠隔武器が敵の弾を相殺できるようにすることで､ゲームの調度の良いゲームバランスと爽快なゲーム体験を
保持し､罪状況を減らしつつ､責の選択肢を増やした｡

ランダム要素について､
敵出現・武器・スキル選択には乱数を用いているが､プレイヤーレベルに応じて出現確率を制御しており、
完全な運ゲーにならないよう設計している｡

最後にシンプルな実装では合ったが､BOSSの単調さを防ぐためにフェーズ制を導入した｡BOSSは複数の攻撃パターンをパラメータstateで切り替えるフェーズ制にし､
戦闘が単調にならないようにした｡どうしても初心者向け武器であるHOLY GREAT SWORDを使っているとBOSSの攻撃を知覚することが､武器の広いレンジによる攻撃相殺によって
感じにくいが､逆に玄人向けの武器を使うことでよりBOSSのアクションを楽しめるゲームになったと解釈できる｡特にBOSSの行動が俗に言うAoEと呼ばれる
攻撃予兆を入れることで理不尽さを回避している｡
